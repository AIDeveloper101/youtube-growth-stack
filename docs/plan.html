Talk to your agent. It analyzes competitor channels, generates titles, ideas, and thumbnails — then talks back. Built agent-first, shipped through pull requests, monetized with Stripe.

Next.js ShadCN + TweakCN Supabase Apify Firecrawl Stripe OpenWhispr Voice-Native Loop Engineering

07

Key Risks

Scraper fragility

High

Isolate scrapers in lib/scrapers/. Cache raw data in Supabase — re-analyze without re-scraping.

API costs

High

Cache results 24h per channel. Hard quotas on the free tier. Price costs into Stripe plans.

Secret leakage

High

All keys in .env.local, gitignored from commit one. Secret scan before every push.

Agent drift

Medium

Loop engineering is the mitigation: small scoped loops, human review on every PR.

Scope creep

Medium

Stick to phase order — every phase ships something demoable on its own.

Voice latency

Medium

Research takes minutes; a silent agent feels broken. Acknowledge instantly, work async, speak when done.

Platform terms

Low

Use maintained Apify actors; keep a migration path to the official YouTube Data API.
